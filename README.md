# Sunfall — The Astral Vault

An original interactive 3D treasure-vault reveal. One tap plays the complete Common → Rare → Epic → Legendary reward sequence.

Open `index.html` directly, or visit the GitHub Pages site. The single HTML file includes its runtime, fonts, original procedural geometry, particles, and synthesized audio; no external assets or server are required.

- Three.js toon shading and normal/depth outlines
- GSAP choreography, hinged chest and dimensional Sunheart relic
- Procedural particles, rolling counters and currency collection
- Mobile layout, mute control and reduced-motion support

Timings: upgrade 5.16s; charge 1.15s; burst 1s; reveal 3.15s; results 1.55s. Edit `VAULT_CONFIG` in `index.html` to tune the presentation.

Libraries: Three.js r160 (MIT), GSAP 3.12.5 (standard license). Fonts: Titan One and Nunito (SIL Open Font License).
